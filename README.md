# group-4_matrix_toolkit
Programming Project
Build a Matrix Toolkit
Design and implement a small command-line program (in C or Python) that:
*Reads two matrices of user-defined size
*Supports insertion, deletion, searching, and updating on a 1D array of values
*Performs matrix addition and multiplication, validating dimensions first
*Display results clearly, and reports which memory allocation strategy (static or dynamic) was used and why
